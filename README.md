# 🤖 AI Interview Prep Platform

An AI-powered Interview Preparation Platform built using the MERN stack. This application helps users practice interviews, generate answers, and improve their communication skills using AI.

---

## 🚀 Features

- 🎤 AI-based Interview Questions
- 💬 Smart Answer Generation
- 🔐 User Authentication (Login/Signup)
- 🧠 Real-time AI Response System
- 📱 Responsive UI

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Tailwind CSS

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB

**Other:**
- JWT Authentication
- AI API (OpenAI / Gemini / etc.)
